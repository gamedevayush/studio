Start the Studio helper

The PPT Creator runs on Ayush's Local LLM, through the Studio helper on your PC.

  1. Start the helper: type studio in the Run box (Win+R), or double-click "Ayush Studio helper" on the Desktop. The creator opens by itself.
  2. Helper already running? Press Open on this PC below.

Chrome and Edge can also run it right on this page: allow "access to apps on this device" when the browser asks. Brave blocks that unless Localhost access is allowed for this site, so use Open on this PC there.
