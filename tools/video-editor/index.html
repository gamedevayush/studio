Nainitor

Ayush's automated video editor. It runs on your own Windows PC, with that PC's processor and graphics card.

Installed on this PC?

Start it from the Nainitor icon on the desktop, then open it here.

Open Nainitor

Your videos stay on the PC that made them.

Install on this PC

Only for Ayush: sign in to download the kit.

After the download

  1. Unzip the kit (right-click, Extract all).
  2. Double-click Install Nainitor.cmd and keep its window open. The first time it downloads what the editor needs: a few GB, several minutes.
  3. When the browser asks, sign in. Then paste the keys it asks for, or press Enter to skip one.
  4. Nainitor opens. Next time, use its desktop icon. To update, download the kit again and run it again.

Windows PCs only. Phones and tablets cannot run the editor.
